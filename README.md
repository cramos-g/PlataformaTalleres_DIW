## ¿Cómo iniciar el proyecto?
Abre el archivo principal *"listado-talleres.html"* en tu navegador. Una vez hecho esto, podrás desplazarte por las diferentes pantallas haciendo uso de los botones implementados.
## Funciones simuladas
| Función                                       | Pantalla                  |
|-----------------------------------------------|---------------------------|
| Ver información detallada sobre un taller     | Listado de talleres       |
| Acceder al formulario de inscripción          | Información detallada     |
| Rellenar y "enviar" formulario de inscripción | Formulario de inscripción |
| Volver a la pantalla del listado              | Pantalla de confirmación  |
